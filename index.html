WHAT I BUILT

เว็บไซต์นี้สร้างขึ้นมาเพื่อแสดงประวัติและข้อมูลส่วนตัวคร่าว ๆ เพื่อให้อาจารย์ประจำวิชา CS100 รู้จักพิ้งค์กี้มากขึ้น

เว็บไซต์นี้เป็น Portfolio แบบหน้าเดียว โดยใช้ภาษา HTML ในการสร้างโครงสร้างของเว็บไซต์ และใช้ CSS ในการจัดรูปแบบและตกแต่งเว็บไซต์ ให้มีความสวยงามและอ่านง่าย

ส่วนประกอบสำคัญของเว็บไซต์

  • About Me - แนะนำข้อมูลส่วนตัว
  • What I Built - อธิบายเกี่ยวกับเว็บไซต์ที่สร้าง
  • How I Built It - อธิบายขั้นตอนการพัฒนา
  • Reflection - สรุปสิ่งที่ได้เรียนรู้และสิ่งที่ต้องการพัฒนาต่อ

Client และ Server

ในขณะที่เปิดเว็บไซต์จากเครื่องของตนเองโดยเปิดไฟล์ index.html โดยตรง Browser จะทำหน้าที่เป็น Client ในการอ่านและแสดงผล HTML และ CSS ส่วนในกรณีนี้ยังไม่มี Web Server เข้ามารับส่งข้อมูล เนื่องจากไฟล์ถูกเปิดจากเครื่องโดยตรงและไม่ได้ร้องขอผ่าน HTTP Server

HOW I BUILT IT

  1. วางแผนและออกแบบโครงสร้างของเว็บไซต์ โดยแบ่งเนื้อหาออกเป็นส่วนต่าง ๆ
  2. ใช้ภาษา HTML ในการสร้างเนื้อหาและโครงสร้างของหน้าเว็บ เช่น heading, paragraph, image, link และ list
  3. สร้างไฟล์ CSS แยกออกจาก HTML เพื่อจัดรูปแบบ สี ขนาดตัวอักษร ระยะห่าง และการจัดวางองค์ประกอบต่าง ๆ
  4. ทดลองเปิดเว็บไซต์และตรวจสอบการแสดงผล ใน Browser เพื่อให้แน่ใจว่าเว็บไซต์แสดงผลตามที่ต้องการ

เครื่องมือและแหล่งข้อมูลที่ใช้

  • สื่อการสอนและสไลด์เรียน - เพื่อทบทวนบทเรียนก่อนการเขียนจริง
  • Visual Studio Code - ใช้สำหรับเขียนโค้ด HTML และ CSS
  • Browser - ใช้สำหรับทดสอบและตรวจสอบการแสดงผลของเว็บไซต์
  • ChatGPT - ใช้ช่วยตรวจสอบข้อผิดพลาดและทำความเข้าใจปัญหาระหว่างทำ

REFLECTION

ปัญหาหรือความท้าทายที่พบ

ปัญหาที่พบในการทำงานนี้คือการทำความเข้าใจโครงสร้างของ HTML และการจัดตำแหน่งขององค์ประกอบต่าง ๆ รวมถึงการเขียน CSS ให้เว็บไซต์มีรูปแบบที่ต้องการ ในช่วงแรกยังสับสนเกี่ยวกับ การใช้ HTML elements และการเชื่อมไฟล์ CSS จึงแก้ปัญหาโดยการทบทวนสื่อการสอน ทดลองเขียนด้วยตนเอง และใช้ Browser ตรวจสอบผลลัพธ์ที่ได้

สิ่งที่เข้าใจมากขึ้นจากการทำ A1

จากการทำ A1 ทำให้เข้าใจมากขึ้นในเรื่องของโครงสร้างแต่ละส่วนของ HTML และการใช้ CSS เข้ามาช่วยในการจัดรูปแบบเว็บไซต์ให้สวยงามมากขึ้น

สิ่งที่อยากพัฒนาต่อ

อยากปรับปรุงการออกแบบเว็บไซต์ให้มีความสวยงามและมีลูกเล่นมากขึ้น เพื่อทำให้ผู้เข้าชมเว็ปไซต์รู้สึกสนใจและสนุกสนานมากขึ้น
